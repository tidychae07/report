### 1. 도달 목표
사용자로부터 모래시계의 높이(홀수 N)를 입력받아, 입력한 크기에 맞는 모래시계 모양을 콘솔 화면에 출력하는 C언어 프로그램을 작성.

---

### 2. 프로그램 흐름과 예시 결과
1. 사용자에게 3 이상의 홀수 N을 입력받음. (ex. 3, 5, 7, 9 ...)
2. 입력받은 N에 맞는 모래시계 출력.

```
// [n=3] 일때
***
 *
***
```

```
// [n=5] 일때
*****
 ***
  *
 ***
*****
```

```
// [n=7] 일때
*******
 *****
  ***
   *
  ***
 *****
*******
```

---

### 3. 프로그램 결과 분석

* **행의 수**
  * 입력한 홀수 N만큼 총 N줄이 출력된다.

* **공백**
  * 첫 번째 줄에는 공백이 없다.
  * 아래로 내려갈수록 앞쪽 공백이 한 칸씩 늘어나다가, 가장 좁은 가운데 줄에서 공백이 가장 많아진다.
  * 가운데를 지나 아래로 내려가면서 다시 공백이 한 칸씩 줄어들어 마지막 줄에서는 공백이 없어진다.

* **별(\*)**
  * 첫 번째 줄에는 N개의 별이 가득 찬 상태로 시작한다.
  * 아래로 한 줄씩 내려갈 때마다 별이 양쪽에서 1개씩 빠져 2개씩 줄어든다.
  * 모래시계의 허리 부분인 정중앙에서는 별이 정확히 1개만 찍힌다.
  * 중앙을 지난 뒤부터는 반대로 매 줄마다 별이 2개씩 다시 늘어나며, 마지막 줄에서는 다시 N개의 별이 출력된다.

* **형태적 대칭성**
  * 중앙의 별 1개인 줄을 기준으로 위쪽 역삼각형과 아래쪽 삼각형이 완벽하게 대칭을 이룬다.

---

### 4. 프로그램 동작 분석

우선 모래시계를 중앙의 1개짜리의 *을 기준으로 상단부(역삼각형 모양)과 하단부(삼각형 모양)으로 분리한다.<br>
또한, 중심이 되는 행의 기준값을 `mid = N / 2`로 정의한다.

1. 첫 행을 0행으로 정의하고, i를 현재 행의 번호라고 한다. (i = 0, 1, 2, ..., mid)
2. 각 행이 시작할 때 공백을 i번 출력한다.
3. 별을 `N - 2i`번 출력한다.
4. 줄바꿈(`\n`)을 한다.
5. `i = mid`가 될 때까지 [2] ~ [4]를 반복한다.<br>
   - 상단부 완성
6. 행 번호 i를 역순으로 사용 정의한다. (i = mid - 1부터 0까지 1씩 감소)
7. 각 행이 시작할 때 공백을 i번 출력한다.
8. 별을 `N - 2i`번 출력한다.
9. 줄바꿈(`\n`)을 한다.
10. `i = 0`이 될 때까지 [7] ~ [9]를 반복한다.<br>
    - 하단부 완성<br>
    - 프로그램 종료

---

### 5. Pseudo-code 로 표현

1. 정수 N을 입력받는다.
2. mid = N / 2 로 설정한다.
3. i를 0부터 mid까지 1씩 증가시키며 반복:
    A. i번 만큼 공백(" ")을 출력한다.
    B. (N - 2 * i)번 만큼 별("*")을 출력한다.
    C. 줄바꿈을 수행한다.
4. i를 mid - 1부터 0까지 1씩 감소시키며 반복:
    A. i번 만큼 공백(" ")을 출력한다.
    B. (N - 2 * i)번 만큼 별("*")을 출력한다.
    C. 줄바꿈을 수행한다.
5. 프로그램을 종료한다.

---

### 6. 코드 해석

```
#include <stdio.h>
```
표준 입출력 함수(`scanf`, `printf`)를 사용하기 위해 표준 입출력 헤더 파일을 포함한다.

<br>

```
int main(void) {
    int n;
    scanf("%d", &n);
```
C언어에서 프로그램의 시작점인 'main' 함수를 정의하고, 사용자로부터 모래시계의 전체 높이가 될 정수 'n'을 선언 후 입력받아 저장한다.

<br>

```
    int mid = n / 2;
```
정수 나눗셈의 특성(두 정수를 나누었을 때 소수점 이하를 버리고 오직 몫(정수)만 반환)을 이용해 모래시계가 가장 좁아지는 별 1개가 찍히는 중앙 기준 행 인덱스(mid)를 계산한다.

<br>

```
    for (int i = 0; i <= mid; i++) {
        for (int j = 0; j < i; j++) {
            printf(" ");
        }
        for (int j = 0; j < n - 2 * i; j++) {
            printf("*");
        }
        printf("\n");
    }
```
**[상단부 & 중앙부(별 1개) 출력]**<br>
* 가장 바깥쪽 for문: 행 번호 'i'를 0부터 'mid'까지 증가시키며 역삼각형 모양을 출력한다.
  * 1번째 내부 for문: 행 번호 'i'만큼 앞쪽 공백을 출력한다.
  * 2번째 내부 for문: 줄마다 별이 2개씩 줄어들도록 'n - 2 * i'개의 별(*)을 출력한다.
* 한 행의 출력이 끝나면 '\n'을 통해 줄바꿈한다.

<br>

```
    for (int i = mid - 1; i >= 0; i--) {
        for (int j = 0; j < i; j++) {
            printf(" ");
        }
        for (int j = 0; j < n - 2 * i; j++) {
            printf("*");
        }
        printf("\n");
    }
```
**[하단부 출력]**<br>
중앙 바로 아랫줄부터 시작하기 위해 'i'를 'mid - 1'부터 0까지 감소시키며 상단부와 대칭되는 삼각형 모양을 출력한다.<br>
* 상단부와 동일한 공식('i'개의 공백, 'n - 2 * i'개의 별)을 역순 인덱스로 재사용하여 대칭 형태를 완성한다.

<br>

```
    return 0;
}
```
운영체제에 0을 반환하며 프로그램을 정상 종료한다.
