# 아스키 피라미드 패턴 출력 (중첩 반복문)

## 1. 문제 개요

* **평가 범위**: 2주차 (반복문, 패턴 그리기)
* **문제 설명**: 높이 $N$을 입력받아 중앙 정렬된 피라미드 형태의 문자 패턴을 출력하는 프로그램 구현
* **조건**:
  * 홀수 번째 행($1, 3, 5, \dots$): `*` 문자 출력
  * 짝수 번째 행($2, 4, 6, \dots$): `#` 문자 출력

## 2. 소스 코드 (`main.c`)

```c
#include <stdio.h>

int main(void) {
    int N;

    // 1. 높이 N 입력받기
    scanf("%d", &N);

    // 2. 피라미드 출력을 위한 중첩 반복문
    for (int i = 1; i <= N; i++) {
        // 2-1. 공백 출력 (N - i 개)
        for (int j = 0; j < N - i; j++) {
            printf(" ");
        }

        // 2-2. 출력할 문자 결정 (홀수 행: '*', 짝수 행: '#')
        char ch = (i % 2 != 0) ? '*' : '#';

        // 2-3. 문자 출력 (2 * i - 1 개)
        for (int j = 0; j < 2 * i - 1; j++) {
            printf("%c", ch);
        }

        // 2-4. 줄바꿈
        printf("\n");
    }

    return 0;
}
```

## 3. 입출력 및 실행 예시

### 예시 1 ($N = 4$)

* **입력**:
  ```text
  4
  ```

* **출력**:
  ```text
     *
    ###
   *****
  #######
  ```

### 예시 2 ($N = 5$)

* **입력**:
  ```text
  5
  ```

* **출력**:
  ```text
      *
     ###
    *****
   #######
  *********
  ```

## 4. 로직 설명

1. **행 단위 반복 (외각 반복문)**:
   * `i`를 $1$부터 $N$까지 증가시켜 피라미드의 각 행을 처리합니다.

2. **공백 출력 연산**:
   * 각 행마다 피라미드 모양을 중앙 정렬하기 위해 `N - i`개의 공백(` `)을 출력합니다.

3. **문자 선택 조건문**:
   * 행 번호 `i`를 $2$로 나눈 나머지(`i % 2`)를 이용하여 홀수 행일 때는 `'*'`, 짝수 행일 때는 `'#'`를 선택합니다.

4. **문자 개수 연산**:
   * 각 행에서 출력할 문자의 개수는 홀수 형태인 `2 * i - 1`개입니다.
