## 📌 [문제 04] 정적 지역 변수 (`static` 키워드)

### 1. 문제
C언어에서 지역 변수(Local Variable) 앞에 `static` 키워드를 붙였을 때 발생하는 특징으로 가장 올바른 것은?

### 2. 보기별 정답/오답 분석

* **① 변수의 값을 변경할 수 없는 상수로 만들어 준다.**
  * **[틀린 이유]:** 변수를 읽기 전용 상수로 만드는 키워드는 `const`입니다. `static` 키워드는 상수화 기능을 제공하지 않습니다.
* **② 함수가 종료되어도 변수가 메모리에서 소멸되지 않고 기존 값을 유지한다. (정답)**
  * **[정답인 이유]:** `static` 지역 변수는 함수가 종료될 때 파괴되는 스택(Stack) 영역이 아니라, 프로그램 시작 시 할당되는 **데이터(Data) 영역**에 저장됩니다. 따라서 함수 호출이 끝나더라도 메모리에서 해제되지 않고 프로그램이 종료될 때까지 기존 값을 계속 유지합니다.
* **③ 해당 변수를 모든 C 소스 파일에서 공유하여 접근할 수 있는 전역 변수로 바꾼다.**
  * **[틀린 이유]:** `static` 지역 변수의 접근 범위(Scope)는 여전히 **선언된 함수 내부로 제한**됩니다. 다른 파일에서 참조할 수 있는 전역 변수로 만들지 않습니다.
* **④ 변수가 선언될 때 메모리의 힙(Heap) 영역에 자동으로 할당된다.**
  * **[틀린 이유]:** 힙(Heap) 영역은 `malloc()`, `calloc()` 등의 함수를 통한 **동적 메모리 할당** 시에 사용되는 영역입니다. `static` 변수는 데이터(Data/BSS) 영역에 정적으로 할당됩니다.

### 3. 핵심 개념 정리
* **`static` 지역 변수의 특징:**
  * **생명 주기(Lifetime):** 프로그램 시작부터 종료 시까지 (데이터 영역)
  * **유효 범위(Scope):** 선언된 함수 내부로 제한 (지역 스코프)
  * **초기화:** 프로그램 실행 시 단 1회만 진행되며, 명시적으로 초기화하지 않으면 $0$으로 자동 초기화됩니다.

## 📌 [문제 06] Visual Studio 정적 라이브러리 생성 (`lib.exe`)

### 1. 문제
Visual Studio 개발자 명령 프롬프트(Developer Command Prompt)에서 `add.obj`와 `sub.obj` 파일로 정적 라이브러리 `my.lib`를 생성할 때 사용하는 `lib` 명령어를 쓰시오.

### 2. 정답 및 풀이
```
lib /OUT:my.lib add.obj sub.obj
```

### 3. 핵심 개념 정리
* Visual Studio 환경(MSVC)에서 오프라인 객체 파일(`.obj`)들을 하나의 정적 라이브러리(`.lib`) 파일로 묶을 때 `lib.exe` 도구를 사용합니다.
* `/OUT:<출력파일명>` 옵션을 지정하고 그 뒤에 묶을 `.obj` 파일 목록을 나열합니다.

## 📌 [문제 07] Linux (WSL) `Makefile` 작성

### 1. 문제
WSL(Linux) 환경에서 `main.c`, `add.c`, `sub.c` 파일로 구성된 C언어 프로젝트의 실행 파일 `./main`을 생성하고자 한다. `gcc` 컴파일러를 이용하여 이를 빌드하는 `Makefile`의 전체 내용을 작성하시오.

### 2. 정답 및 풀이

```
CC = gcc
CFLAGS = -Wall -Wextra -O2
TARGET = main
OBJS = main.o add.o sub.o

# 기본 타깃 (전체 빌드)
all: $(TARGET)

# 실행 파일 생성 규칙
$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) -o $@ $^

# 개별 소스 파일의 오브젝트 파일 컴파일 규칙
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# 빌드 부산물 삭제 규칙
clean:
	rm -f $(OBJS) $(TARGET)
```

### 3. 핵심 개념 정리
* **기본 구조:** 
  $$\text{Target} : \text{Dependencies}$$
  $$\quad \text{[TAB]} \text{Command}$$
  *(주의할 점: 명령 실행 줄에는 반드시 공백 스페이스가 아닌 **TAB 키**로 들여쓰기해야 함)*
* **자동 변수:**
  * `$@`: 현재 타깃(Target) 이름
  * `$^`: 의존성(Dependencies) 파일 전체 목록
  * `$<`: 의존성 파일 목록 중 첫 번째 파일 이름

## 📌 [문제 08] 이중 `for`문 실행 줄(line) 수 계산

### 1. 문제
다음 C언어 코드를 실행했을 때, 화면에 출력되는 전체 줄(line) 수는 얼마인지 쓰시오. (단, 개행 문자 `\n`을 기준으로 한 줄을 카운트함) (숫자만 기재)

```c
#include <stdio.h>

void main(void) {
    for (int i = 2; i <= 4; i++) {
        for (int j = 1; j <= 5; j++) {
            printf("%d*%d=%d\n", i, j, i*j);
        }
    }
}
```

### 2. 정답 및 풀이
* **정답:** `15`

* **풀이 과정:**
  1. 외부 `for`문: `i`는 $2$부터 $4$까지 $1$씩 증가하므로 총 $3$회 실행됩니다 ($i \in \{2, 3, 4\}$).
  2. 내부 `for`문: `j`는 $1$부터 $5$까지 $1$씩 증가하므로 총 $5$회 실행됩니다 ($j \in \{1, 2, 3, 4, 5\}$).
  3. `printf` 함수 실행 횟수:
     $$\text{전체 실행 횟수} = 3 \times 5 = 15\text{회}$$
  4. `printf` 출력 문자열 내에 개행 문자 `\n`이 매번 포함되어 있으므로 총 **$15$줄**이 출력됩니다.

## 📌 [문제 13] 구조체 포인터를 활용한 멤버 합계 구하기

### 1. 문제
정수 멤버 `a`, `b`를 갖는 구조체 `pair`를 정의하고 `a=22`, `b=55`로 초기화하시오. 이 변수의 주소를 `add` 함수에 전달하여 포인터로 두 멤버의 합을 구해 리턴하고, `main` 함수에서 출력하는 프로그램을 작성하시오.

### 2. 정답 코드

```c
#include <stdio.h>

// 1. 정수 멤버 a, b를 갖는 구조체 pair 정의
typedef struct {
    int a;
    int b;
} Pair;

// 2. 구조체 포인터를 전달받아 두 멤버의 합을 리턴하는 add 함수
int add(const Pair *p) {
    return p->a + p->b; // 포인터 간접 접근 연산자(->) 활용
}

int main(void) {
    // 3. 구조체 변수 선언 및 a=22, b=55로 초기화
    Pair pair_var = {22, 55};

    // 4. 구조체 변수의 주소를 add 함수에 전달하여 결과 계산
    int result = add(&pair_var);

    // 5. 결과 출력
    printf("두 멤버의 합: %d\n", result);

    return 0;
}
```

### 3. 핵심 개념 정리
* **구조체 포인터 접근 연산자 (`->`):**
  포인터 변수를 통해 구조체 멤버에 접근할 때는 `p->a` 또는 `(*p).a` 연산자를 사용합니다.
* **Call by Reference (주소 전달):**
  구조체 전체를 복사해서 전달하는 대신 주소(`&pair_var`)만 전달하므로 메모리 복사 비용을 줄일 수 있습니다.
