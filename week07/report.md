### [문제 1] 개념 점검 (단답형 / 약술형)

#### (1) `int a = 10; int *p = &a;` 코드에서 `*p`의 값과 `p`의 값이 각각 의미하는 바를 설명하시오.

> **💡 집주소 비유로 이해하기**
> 
> 변수 `a`를 **'실제 집'**, 그 안에 살고 있는 `10`을 **'집 안의 거주자'**, 포인터 `p`를 **'집 주소가 적힌 종이'**라고 비유할 수 있습니다.

* **`p`의 값 (집 주소)**
  * 포인터 변수 `p` 자체가 가지고 있는 값입니다. 즉, 변수 `a`라는 집이 존재하는 메모리의 위치(주소지)를 의미합니다. (예: `0x7fff5fbff6ac`)

* **`*p`의 값 (집 안의 내용물)**
  * 주소지(`p`)를 찾아가서(**역참조**) 확인한 집 안의 실제 거주자인 데이터 값 `10`을 의미합니다.

#### (2) C언어에서 일반 변수 전달(Call by Value)과 포인터 전달(Call by Reference)의 차이점을 '메모리' 관점에서 설명하시오.

* **Call by Value (값에 의한 호출)**
  * 호출된 함수의 매개변수를 위한 **별도의 메모리 공간이 새로 스택(Stack)에 할당**되며, 인자로 전달받은 변수의 **'값'만 복사**됩니다.
  * 따라서 함수 내부에서 매개변수의 값을 수정하더라도, 호출한 원본 변수가 위치한 메모리 영역에는 영향을 주지 않습니다.

* **Call by Reference (포인터를 이용한 참조 호출)**
  * 원본 변수의 **'메모리 주소'를 포인터 매개변수로 전달**받습니다.
  * 함수 내부에서 역참조 연산자(`*`)를 사용하면 호출한 쪽의 **원본 메모리 공간에 직접 접근**하므로, 함수 내부에서의 수정이 원본 데이터에 즉시 반영됩니다.

#### (3) `void *` (범용 포인터)를 사용할 때 주의해야 할 점(형변환 등)을 약술하시오.

* `void *`는 대상 메모리의 **자료형(Type) 정보와 크기(Size) 정보가 없는 포인터**입니다.
* 따라서 **역참조 연산(`*p`)이나 포인터 연산(`p + 1`)을 직접 수행할 수 없습니다.**
* 반드시 연산이나 접근을 수행하기 전 `(int *)p`나 `(char *)p`와 같이 명시적 형변환(Type Casting)을 거쳐 가리키는 데이터의 타입을 지정해야 합니다.

### [문제 2] 코드 작성 및 분석 (실습형)

#### (1) 두 정수의 값을 서로 바꾸는 `swap` 함수를 포인터를 활용하여 완성하시오.

* **함수 원형**: `void swap(int *x, int *y)`

```c
#include <stdio.h>

void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}

int main(void) {
    int a = 10, b = 20;
    swap(&a, &b);
    return 0;
}
```

#### (2) 크기가 5인 정수 배열 `int arr[5] = {10, 20, 30, 40, 50};`이 있을 때, 대괄호 연산자(`[]`)를 전혀 사용하지 않고 '포인터 연산(`*`)'만을 사용하여 배열의 모든 요소를 출력하는 C 코드를 작성하시오.

```c
#include <stdio.h>

int main(void) {
    int arr[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("%d ", *(arr + i));
    }
    printf("\n");

    return 0;
}
```

* 가) `qsort()` 함수에 비교 기준 전달
* 나) `malloc()`을 이용한 가변 배열 생성
* **다) `#define` 문을 이용한 상수의 정의**
